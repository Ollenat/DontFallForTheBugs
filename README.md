# Dont fall for the bugs
Vampire survivors men det är bugs som attackerar. Varje level man går upp faller man ned ett floor i tornet/byggnaden/skyskrapan. 
Man får då olika vapen/passives för att döda fler och fler inseker. Man kan också hitta kistor och sånt när man går runt för att få nya buffs. Det är pick 3 också som alla andra spel. Och det är isometric.

Vad vi behöver:
- Movement
- Isometric follow camera
- Fiender
- Falling down
- Pick 3 upgrade system
- Vapen och upgrades
- Sjuka shaders
- Bedbugs som fiender och vill få dig att somna
- Andra galna bugs som är fiender
